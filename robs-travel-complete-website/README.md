# Rob's Travel Taxis — ready to upload

This package is prepared for:

- GitHub repository: `robs-travel-taxis`
- Cloudflare Pages project: `robs-travel-taxis`
- Main domain: `https://robs-travel.co.uk`

## Cloudflare Pages settings

- Framework preset: `None`
- Production branch: `main`
- Build command: leave empty
- Build output directory: `/`

## Upload from Samsung / Android

1. Download this ZIP.
2. Open **My Files** > **Downloads**.
3. Tap the ZIP and choose **Extract**.
4. Open the extracted folder.
5. In GitHub, open the `robs-travel-taxis` repository.
6. Tap **Add file** > **Upload files**.
7. Upload everything inside the extracted folder.
8. Commit directly to `main`.
9. Cloudflare will deploy automatically.

## Custom domain

In Cloudflare Pages:

1. Open `robs-travel-taxis`.
2. Open **Custom domains**.
3. Add `robs-travel.co.uk`.
4. Add `www.robs-travel.co.uk`.
5. Keep `robs-travel.co.uk` as the main address.
